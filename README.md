# n2a2ui

This pnpm workspace contains the [`n2a2ui`](./packages/n2a2ui) TypeScript
package, which converts Notion block trees into A2UI v0.9 surfaces and
progressive messages.

See the [package README](./packages/n2a2ui/README.md) for installation, API, and
conversion details.

## Development

```bash
pnpm install --frozen-lockfile
just ci
```
